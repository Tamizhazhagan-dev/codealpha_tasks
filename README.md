# codealpha_tasks HR Analytics Dashboard – Power BI

This project contains a complete HR Analytics Dashboard built in Microsoft Power BI, covering recruitment, turnover, employee satisfaction, performance, and predictive analytics.
It includes three key report pages:

📌 Page 1 – Recruitment & Turnover Metrics

Monthly hiring trend

Attrition rate

Attrition by department

Headcount trend

📌 Page 2 – Employee Satisfaction & Performance

Average satisfaction score

Satisfaction vs performance scatter plot

Satisfaction and performance by department

📌 Page 3 – Predictive Analytics

Forecasted attrition for next 6 months

What-If parameter for attrition %

What-If parameter for target hiring

Adjusted attrition calculation

Predicted next-year employee count

🛠 Tools Used

Power BI

DAX Measures

What-If parameters

Forecasting analytics
